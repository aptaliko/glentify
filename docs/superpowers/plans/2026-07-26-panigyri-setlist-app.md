# Panigyri Setlist App Implementation Plan

> **Status: COMPLETE (foundational).** This is the original MVP plan — folded into the repo's initial commit (`8bc238c`) rather than tracked as individual per-task commits (no granular history exists from before that point). The app running today is its delivered outcome. Its data model has since evolved past what this plan originally describes (see `2026-07-29-dynamic-song-tags.md` and `2026-08-12-remove-genre-column.md` for the axis-based classification that replaced the fixed region/rhythm/dromos/genre columns this plan specifies) — read this for MVP-era context, not current schema.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-user, tablet-friendly web app that stores Greek folk/laiko songs with lyrics and metadata (region, rhythm, dromos, genre), and during a live performance shows the current song's lyrics alongside three ranked suggestion lists for what to play next, respecting configurable rhythm-transition rules.

**Architecture:** Next.js (App Router, TypeScript) full-stack app. Postgres hosted on Neon, accessed via Drizzle ORM. A pure, dependency-free suggestion engine (`src/lib/suggestions.ts`) implements the ranking/filtering logic and is unit-tested exhaustively; everything else (CRUD admin screens, live session UI) is a thin layer over that engine and is tested manually via curl/browser. Deployed to Vercel.

**Tech Stack:** Next.js 14+ (App Router), TypeScript, Tailwind CSS, Drizzle ORM, `@neondatabase/serverless`, Neon Postgres, Zod (API input validation), Vitest, Vercel.

## Global Constraints

- TypeScript end-to-end (app code, scripts, tests) — no plain JS files.
- Database: Postgres hosted on Neon (free tier). ORM: Drizzle.
- Deploy target: Vercel (Hobby/free plan). Total running cost must stay $0 at MVP scale (one user, a few thousand songs).
- Auth: a single shared app password via env var (`APP_PASSWORD`) with a signed cookie (`AUTH_SECRET`). No user accounts, no multi-user access.
- UI copy is in Greek and must match the spec's exact wording where it defines a control: "Ξεκίνα γλέντι", "Τέλος σειράς", "Λήξη session", "Δείξε και τα ειπωμένα".
- Every song has exactly one `region`, one `rhythm`, one `dromos`, one `genre` (no multi-value metadata).
- Explicitly out of scope for this plan: offline support, multi-user/multi-device sessions, modeling "sequences" as their own entity, multi-value song metadata. Do not build these.
- Per the spec's Testing section: only the suggestion engine (`src/lib/suggestions.ts`) gets heavy automated unit tests. CRUD/admin screens and the live session UI are verified manually (curl for APIs, browser for pages) — do not write UI component tests or DB-integration tests beyond the smoke scripts this plan specifies.

```ts
import type { SongRow, TransitionRuleRow } from '@/db/schema';

export function getAllowedNextRhythmIds(
  currentRhythmId: number,
  transitionRules: TransitionRuleRow[]
): Set<number> | null {
  const matching = transitionRules.filter((r) => r.fromRhythmId === currentRhythmId);
  if (matching.length === 0) return null;
  return new Set([currentRhythmId, ...matching.map((r) => r.toRhythmId)]);
}

export function getCandidatePool(params: {
  currentSong: SongRow;
  allSongs: SongRow[];
  transitionRules: TransitionRuleRow[];
  playedSongIds: Set<number>;
  showPlayed: boolean;
}): SongRow[] {
  const { currentSong, allSongs, transitionRules, playedSongIds, showPlayed } = params;
  const allowedRhythmIds = getAllowedNextRhythmIds(currentSong.rhythmId, transitionRules);

  return allSongs.filter((song) => {
    if (song.id === currentSong.id) return false;
    if (!showPlayed && playedSongIds.has(song.id)) return false;
    if (allowedRhythmIds !== null && !allowedRhythmIds.has(song.rhythmId)) return false;
    return true;
  });
}
```

```ts
export type Axis = 'rhythm' | 'region' | 'dromos';

const AXIS_KEY: Record<Axis, keyof SongRow> = {
  rhythm: 'rhythmId',
  region: 'regionId',
  dromos: 'dromosId',
};

const AXIS_PRIORITY: Axis[] = ['rhythm', 'region', 'dromos'];

export function rankCandidates(candidates: SongRow[], currentSong: SongRow, anchorAxis: Axis): SongRow[] {
  const secondaryAxes = AXIS_PRIORITY.filter((axis) => axis !== anchorAxis);
  const [firstAxis, secondAxis] = secondaryAxes;

  function score(song: SongRow): number {
    let total = 0;
    if (song[AXIS_KEY[firstAxis]] === currentSong[AXIS_KEY[firstAxis]]) total += 2;
    if (song[AXIS_KEY[secondAxis]] === currentSong[AXIS_KEY[secondAxis]]) total += 1;
    return total;
  }

  return [...candidates].sort((a, b) => {
    const diff = score(b) - score(a);
    if (diff !== 0) return diff;
    return a.title.localeCompare(b.title, 'el');
  });
}
```

```ts
import type { RegionRow } from '@/db/schema';

export function getSiblingRegionIds(regionId: number, regions: RegionRow[]): number[] {
  const current = regions.find((r) => r.id === regionId);
  if (!current) return [];
  return regions
    .filter((r) => r.id !== regionId && r.parentId === current.parentId)
    .map((r) => r.id);

export interface SuggestionParams {
  currentSong: SongRow;
  allSongs: SongRow[];
  regions: RegionRow[];
  transitionRules: TransitionRuleRow[];
  playedSongIds: Set<number>;
  showPlayed: boolean;

export interface SuggestionLists {
  byRhythm: SongRow[];
  byRegion: SongRow[];
  byDromos: SongRow[];
}

export function getSuggestions(params: SuggestionParams): SuggestionLists {
  const { currentSong, allSongs, regions, transitionRules, playedSongIds, showPlayed } = params;
  const pool = getCandidatePool({ currentSong, allSongs, transitionRules, playedSongIds, showPlayed });

  const byRhythm = rankCandidates(
    pool.filter((s) => s.rhythmId === currentSong.rhythmId),
    currentSong,
    'rhythm'
  );

  const byDromos = rankCandidates(
    pool.filter((s) => s.dromosId === currentSong.dromosId),
    currentSong,
    'dromos'
  );

  const sameRegion = pool.filter((s) => s.regionId === currentSong.regionId);
  let byRegion: SongRow[];
  if (sameRegion.length > 0) {
    byRegion = rankCandidates(sameRegion, currentSong, 'region');
  } else {
    const siblingIds = getSiblingRegionIds(currentSong.regionId, regions);
    const siblingSongs = pool.filter((s) => siblingIds.includes(s.regionId));
    byRegion = rankCandidates(siblingSongs, currentSong, 'region');
  }

  return { byRhythm, byRegion, byDromos };
}
```

```ts
import { createHmac } from 'crypto';

const COOKIE_NAME = 'panigyri_auth';

function getExpectedToken(): string {
  const secret = process.env.AUTH_SECRET;
  if (!secret) throw new Error('AUTH_SECRET env var is not set');
  return createHmac('sha256', secret).update('authenticated').digest('hex');
}

export function isValidPassword(password: string): boolean {
  return password === process.env.APP_PASSWORD;
}

export function getAuthCookieName(): string {
  return COOKIE_NAME;
}

export function getAuthCookieValue(): string {
  return getExpectedToken();
}

export function isAuthCookieValid(value: string | undefined): boolean {
  if (!value) return false;
  return value === getExpectedToken();
}
```

```ts
import { NextRequest, NextResponse } from 'next/server';
import { getAuthCookieName, isAuthCookieValid } from '@/lib/auth';

export function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl;

  if (pathname === '/login' || pathname === '/api/login') {
    return NextResponse.next();
  }

  const cookie = request.cookies.get(getAuthCookieName())?.value;
  if (!isAuthCookieValid(cookie)) {
    if (pathname.startsWith('/api/')) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    const loginUrl = new URL('/login', request.url);
    return NextResponse.redirect(loginUrl);
  }

  return NextResponse.next();
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)'],
};
```

```ts
import { db } from '../client';
import { transitionRules } from '../schema';
import { eq, and } from 'drizzle-orm';
import type { TransitionRuleRow } from '../schema';

export async function listTransitionRules(): Promise<TransitionRuleRow[]> {
  return db.select().from(transitionRules);
}

export async function createTransitionRule(data: { fromRhythmId: number; toRhythmId: number }): Promise<TransitionRuleRow> {
  const existing = await db
    .select()
    .from(transitionRules)
    .where(and(eq(transitionRules.fromRhythmId, data.fromRhythmId), eq(transitionRules.toRhythmId, data.toRhythmId)));
  if (existing.length > 0) throw new Error('Αυτός ο κανόνας μετάβασης υπάρχει ήδη');
  const rows = await db.insert(transitionRules).values(data).returning();
  return rows[0];
}

export async function deleteTransitionRule(id: number): Promise<void> {
  await db.delete(transitionRules).where(eq(transitionRules.id, id));
}
```

```ts
import { db } from '../client';
import { songs } from '../schema';
import { eq, ilike, and, type SQL } from 'drizzle-orm';
import type { SongRow } from '../schema';

export interface SongFilters {
  search?: string;
  regionId?: number;
  rhythmId?: number;
  dromosId?: number;
  genreId?: number;
}

export async function listSongs(filters: SongFilters = {}): Promise<SongRow[]> {
  const conditions: SQL[] = [];
  if (filters.search) conditions.push(ilike(songs.title, `%${filters.search}%`));
  if (filters.regionId) conditions.push(eq(songs.regionId, filters.regionId));
  if (filters.rhythmId) conditions.push(eq(songs.rhythmId, filters.rhythmId));
  if (filters.dromosId) conditions.push(eq(songs.dromosId, filters.dromosId));
  if (filters.genreId) conditions.push(eq(songs.genreId, filters.genreId));

  if (conditions.length === 0) return db.select().from(songs);
  return db.select().from(songs).where(and(...conditions));
}

export async function getSongById(id: number): Promise<SongRow | undefined> {
  const rows = await db.select().from(songs).where(eq(songs.id, id));
  return rows[0];
}

export async function createSong(data: {
  title: string;
  lyrics: string;
  regionId: number;
  rhythmId: number;
  dromosId: number;
  genreId: number;
  notes: string | null;
}): Promise<SongRow> {

  return rows[0];
}

    title: string;
    lyrics: string;
```

```ts
import { sessions, sessionPlayedSongs } from '../schema';
import { eq, isNull, desc } from 'drizzle-orm';
import type { SessionRow } from '../schema';

export async function getActiveSession(): Promise<SessionRow | undefined> {
  const rows = await db.select().from(sessions).where(isNull(sessions.endedAt)).orderBy(desc(sessions.startedAt));
  return rows[0];
}

export async function createSession(label: string | null, startingSongId: number): Promise<SessionRow> {
  const rows = await db.insert(sessions).values({ label, currentSongId: startingSongId }).returning();
  return rows[0];
}

export async function getSessionById(id: number): Promise<SessionRow | undefined> {
  const rows = await db.select().from(sessions).where(eq(sessions.id, id));
  return rows[0];
}

export async function getPlayedSongIds(sessionId: number): Promise<number[]> {
  const rows = await db
    .select({ songId: sessionPlayedSongs.songId })
    .from(sessionPlayedSongs)
    .where(eq(sessionPlayedSongs.sessionId, sessionId));
  return rows.map((r) => r.songId);
}

async function markCurrentAsPlayedIfAny(sessionId: number, currentSongId: number | null): Promise<void> {
  if (currentSongId !== null) {
    await db.insert(sessionPlayedSongs).values({ sessionId, songId: currentSongId });
  }
}

export async function advanceToSong(sessionId: number, nextSongId: number): Promise<void> {
  const session = await getSessionById(sessionId);
  if (!session) throw new Error(`Session ${sessionId} not found`);
  await markCurrentAsPlayedIfAny(sessionId, session.currentSongId);
  await db.update(sessions).set({ currentSongId: nextSongId }).where(eq(sessions.id, sessionId));
}

export async function endSequence(sessionId: number): Promise<void> {
  const session = await getSessionById(sessionId);
  if (!session) throw new Error(`Session ${sessionId} not found`);
  await markCurrentAsPlayedIfAny(sessionId, session.currentSongId);
  await db.update(sessions).set({ currentSongId: null }).where(eq(sessions.id, sessionId));
}

export async function endSession(sessionId: number): Promise<void> {

  if (!session) throw new Error(`Session ${sessionId} not found`);
  await markCurrentAsPlayedIfAny(sessionId, session.currentSongId);
```

- Produces: `GET /api/sessions/:id/suggestions?showPlayed=true|false` returning `{ currentSong: SongRow | null, byRhythm: SongRow[], byRegion: SongRow[], byDromos: SongRow[] }`. Consumed by Task 17 (live page).

- [ ] **Step 1: Write the route**

Create `src/app/api/sessions/[id]/suggestions/route.ts`:

```ts
import { NextRequest, NextResponse } from 'next/server';
import { getSessionById, getPlayedSongIds } from '@/db/queries/sessions';
import { listSongs } from '@/db/queries/songs';
import { listRegions } from '@/db/queries/regions';
import { listTransitionRules } from '@/db/queries/transitionRules';
import { getSuggestions } from '@/lib/suggestions';

export async function GET(request: NextRequest, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const sessionId = Number(id);
  const session = await getSessionById(sessionId);
  if (!session) return NextResponse.json({ error: 'Δεν βρέθηκε session' }, { status: 404 });

  const showPlayed = request.nextUrl.searchParams.get('showPlayed') === 'true';

  if (session.currentSongId === null) {
    return NextResponse.json({ currentSong: null, byRhythm: [], byRegion: [], byDromos: [] });
  }

  const [allSongs, regions, transitionRules, playedSongIdList] = await Promise.all([
    listSongs(),
    listRegions(),
    listTransitionRules(),
    getPlayedSongIds(sessionId),
  ]);

  const currentSong = allSongs.find((s) => s.id === session.currentSongId);
  if (!currentSong) return NextResponse.json({ error: 'Το τρέχον τραγούδι δεν βρέθηκε' }, { status: 500 });

  const lists = getSuggestions({
    currentSong,
    allSongs,
    regions,
    transitionRules,
    playedSongIds: new Set(playedSongIdList),
    showPlayed,
  });

  return NextResponse.json({ currentSong, ...lists });
}
```

```tsx
'use client';

import { useCallback, useEffect, useState } from 'react';
import { useParams, useRouter } from 'next/navigation';
import SongPicker from '@/components/SongPicker';

interface Song {
  id: number;
  title: string;
  lyrics: string;
}

interface SuggestionsResponse {
  currentSong: Song | null;
  byRhythm: Song[];
  byRegion: Song[];
  byDromos: Song[];
}

export default function LiveSessionPage() {
  const params = useParams<{ id: string }>();
  const router = useRouter();
  const [data, setData] = useState<SuggestionsResponse | null>(null);
  const [showPlayed, setShowPlayed] = useState(false);

  const load = useCallback(async () => {
    const res = await fetch(`/api/sessions/${params.id}/suggestions?showPlayed=${showPlayed}`);
    setData(await res.json());
  }, [params.id, showPlayed]);

  useEffect(() => {
    load();
  }, [load]);

  async function handlePick(songId: number) {
    await fetch(`/api/sessions/${params.id}/advance`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ nextSongId: songId }),
    });
    await load();
  }

  async function handleEndSequence() {
    await fetch(`/api/sessions/${params.id}/end-sequence`, { method: 'POST' });
    await load();
  }

  async function handleEndSession() {
    await fetch(`/api/sessions/${params.id}/end`, { method: 'POST' });
    router.push('/');
  }

  if (!data) return <main className="p-4">Φόρτωση...</main>;

  if (!data.currentSong) {
    return (
      <main className="flex min-h-screen flex-col items-center justify-center gap-6 p-4">
        <h1 className="text-2xl font-bold">Διάλεξε τραγούδι για να συνεχίσεις</h1>
        <SongPicker onSelect={handlePick} />
      </main>
    );
  }

  function SuggestionColumn({ title, songs }: { title: string; songs: Song[] }) {
    return (
      <div className="flex-1 min-w-[200px]">
        <h2 className="font-bold mb-2">{title}</h2>
        {songs.length === 0 && <p className="text-gray-500 text-sm">Καμία πρόταση</p>}
        <ul className="flex flex-col gap-1">
          {songs.map((s) => (
            <li key={s.id}>
              <button onClick={() => handlePick(s.id)} className="w-full text-left border p-2 hover:bg-gray-100">
                {s.title}
              </button>
            </li>
          ))}
        </ul>
      </div>
    );
  }

  return (
    <main className="flex flex-col min-h-screen p-4 gap-4">
      <div className="flex justify-between items-center">
        <h1 className="text-2xl font-bold">{data.currentSong.title}</h1>
        <div className="flex gap-2">
          <button onClick={handleEndSequence} className="border p-2">Τέλος σειράς</button>
          <button onClick={handleEndSession} className="border p-2 bg-red-600 text-white">Λήξη session</button>
        </div>
      </div>

      <label className="flex gap-2 items-center">
        <input type="checkbox" checked={showPlayed} onChange={(e) => setShowPlayed(e.target.checked)} />
        Δείξε και τα ειπωμένα
      </label>

      <div className="flex flex-col lg:flex-row gap-6">
        <pre className="flex-1 whitespace-pre-wrap font-sans text-lg border p-4 min-w-[250px]">{data.currentSong.lyrics}</pre>
        <div className="flex flex-1 gap-4 flex-wrap">
          <SuggestionColumn title="Προτάσεις βάσει ρυθμού" songs={data.byRhythm} />
          <SuggestionColumn title="Προτάσεις βάσει περιοχής" songs={data.byRegion} />
          <SuggestionColumn title="Προτάσεις βάσει δρόμου" songs={data.byDromos} />
        </div>
      </div>
    </main>
  );
}
```
